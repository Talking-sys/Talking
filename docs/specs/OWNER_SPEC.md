# Спецификация Talking — вклад владельца (verbatim)

Сохранено дословно по запросу владельца как доказательство человеческого вклада.
Дата фиксации в репозитории: 2026-11-03. Автор спецификации: hateaboutyouone.
Контакт: hateaboutyou111@icloud.com.

Ниже — полный текст постановки, без редактирования содержания.

---

Создай полноценное приложение Talking в репозитории Talking-sys/Talking на GitHub. Лицензия — GPL v3 (уже в репозитории), коммерческая монетизация через open core: ядро (перевод, чат, игры, буфер) открыто под GPL, коммерческие модули (админка, лицензирование, Talk-коины, P2P-платежи, аналитика) — отдельный репозиторий под проприетарной лицензией «Все права защищены», правообладатель hateaboutyouone, общаются через открытый API без прямой линковки.

Стек: Python 3.12, FastAPI, WebSocket, PostgreSQL (Neon), Redis, R2-хранилище (Cloudflare), Docker. Фронт — HTML/JS, мобильный доступ через браузер (Kivy — второй этап). Распознавание: Whisper large-v3 по умолчанию с переключателем на base/medium/small в настройках. Перевод: Grok API через переменную XAI_API_KEY, fallback на бесплатный канал без ключа. Озвучка: браузерный Web Speech API (edge-tts и espeak-ng — GPL, вынести в отключённые опции, заменить gTTS). Геокодирование: Nominatim. OCR: Tesseract локально + Qwen-OCR для арабского и азиатских. Роутер языков: Whisper для европейских, Qwen3-ASR для китайского, Naver CLOVA для корейского, MMS от Meta для суахили/хауса/йоруба. Перевод азиатских: DeepSeek V4.1 Flash, арабских: Qwen/Command R Plus с RTL. Хостинг: AWS EKS три региона (Вирджиния, Франкфурт, Токио) через Global Accelerator, Aurora Global Database, PgBouncer, HPA, SQS/Redis очереди, Cloudflare CDN. Домен через Cloudflare Registrar.

Функции: 1) Двусторонний перевод речи в реальном времени, буфер три минуты на всех языках. 2) Офлайн-буфер: распознавание локальное, текст пишется в JSONL с таймкодами, при появлении сети уходит пакетом в хронологическом порядке, удаляется только после успешного перевода. 3) Распознавание автоматическое (Whisper определяет язык), перевод — ручной выбор или голосовая команда («переведи на немецкий»), команды обрабатываются локально. 4) VAD через Silero в браузере (Web Audio API) + запасной на сервере, диапазон паузы 300-3000 мс, дефолт 800 мс, лимит сегмента 15-20 сек. 5) Два слоя хранения: локальный для офлайна, S3-совместимый архив для истории длиннее трёх минут, ключи через переменные окружения S3_*, без ключей работает локально. 6) Двусторонний режим: если собеседник говорит на языке перевода, речь автоматически переводится обратно. 7) Веб-интерфейс на FastAPI, телефон подключается к серверу в той же Wi-Fi, самоподписанный сертификат для HTTPS (требование браузерного микрофона). 8) Нативная Kivy-версия — второй этап. 9) Мобильная оптимизация: по умолчанию base/small Whisper, квантизация ONNX, кольцевой буфер на диск. 10) Коммерция: лицензия с trial и paid, подписка через мок-эндпоинт под Stripe, чистый UI, лендинг с ценами, privacy и terms как шаблоны под юриста, Docker-сборка, rate limiting. Trial: максимум один час в день (скользящее окно 24 часа), жёсткий стоп приложения, реклама каждые 15 минут внутри trial — два ролика по 30 секунд, кнопка «Пропустить» появляется на 15-й секунде каждого ролика, сервер сверяет собственный старт ролика. Free: реклама тоже есть. Paid: без рекламы. Длительность роликов и порог пропуска настраиваются из админки. 11) Админ-панель под секретным токеном (токен в заголовке или одноразовая форма входа с кукой, не в URL): выпуск лицензий, отзыв через список отозванных ключей, откат версий, мониторинг, загрузка стикеров через ZIP с манифестом, настройка стартовой суммы для Sic Bo, курс Talk-коинов, длительность рекламы, порог пропуска, аналитика (показы/досмотры рекламы, конверсия в paid, активные сессии, языки, ошибки API, графики, фильтр по периоду, экспорт CSV без инъекций формул, события с хэшированием user_id, очистка по retention). Пересборка Docker из панели выключена по умолчанию. Локальный git с тегом v0.1.0. 12) Безопасность: AES-256-GCM для полей подписок/балансов (ключ DB_ENCRYPTION_KEY), pgcrypto как опция для прода, хэширование user_id в логах, сессии с TTL, 2FA для админки, проверка подписи платёжных вебхуков, карты не хранятся, файлы перекодируются, EXIF стрипается, скачивание по одноразовым токенам, мини-браузер в sandbox без javascript/data-схем, внутренние адреса блокируются серверной проверкой заголовков, BLE шифруется X25519+AES-256-GCM с шестизначным кодом сопряжения, QR-токены одноразовые, лицензии подписаны (в сборке только публичный ключ), trial/рекламные таймеры серверные, auto-delete сообщений на сервере через 3 минуты после перевода (бэкапы и реплики чистятся по тому же TTL), на телефоне история: без лимита или час/день/неделя/месяц/полгода/год, дефолт для нового чата — полгода, управление таймером в строке набора текста как в Telegram (иконка таймера рядом с полем ввода, в группах общий таймер меняет только админ). 13) Авторизация: Google (scopes: openid, email, profile, без sensitive; чеклист верификации в GOOGLE_SCOPES.md; OAuth-клиент на каждую платформу), Apple (Sign in with Apple рядом с Google с равной заметностью, приватный relay-email, удаление аккаунта), почта passwordless (magic link/одноразовый код, токены 10 мин, хэш в базе), passkeys через WebAuthn. SMS-вход — не в первой версии. Аккаунты анонимные без пароля: одноразовый код восстановления показывается один раз. Совпадение почт не склеивает аккаунты автоматически — только после подтверждения владельца. 14) Платежи: Apple Pay через Apple Pay JS (merchant ID, валидация домена), PayPal через JS SDK (редирект для цифровых подписок на iOS), Blink es-vi как крипто-опция (Lightning, генерация инвойса, проверка статуса через API), внутренняя P2P: ник hateaboutyouone, внутренний баланс в стейблкоине, перевод по нику с подтверждением второй стороной. Админка: вкл/выкл каждого метода, лимиты сумм, журнал транзакций без ПДн. На iOS для цифровых подписок — in-app purchase по требованию Apple, PayPal через браузерный редирект. 15) Внутренняя валюта Talk-коины: два баланса — купленные за реальные деньги и заработанные (игры не дают коинов, только очки рейтинга). Покупка Premium за Talk-коины (год за 100000, курс из админки). Подарки: 12 на старт с ценами/редкостью/анимацией, каждый апгрейд добавляет набор, старые не удаляются, дарятся/передариваются/продаются обратно за коины (комиссия 10%, редкостные/анимированные не продаются), передаривание бесплатно с лимитом 5 в день, история подарка видна владельцу. Приватность подарков: по умолчанию скрыты, публикуются явно, скрытые не рендерятся в чужих профилях. При открытии профиля — сетка публичных подарков. 16) Чат: ники уникальные (смена раз в 30 дней), поиск по префиксу как в Telegram, WebSocket, сообщения до 500 символов, блокировка, rate limit 10/мин, диалоги админка не видит. Мгновенный перевод в чате: каждый пишет на своём, собеседник видит на родном, оригинал под «Показать оригинал», кэширование переводов, перевод идёт всегда даже при совпадении языков (при сбое API — оригинал с пометкой), фильтр команд для переводчика. Камера (getUserMedia), галерея, файлы до 25 МБ (чёрный список опасных расширений), UUID-имена в uploads, 500 МБ лимит на пользователя. Стикеры: встроенные паки в assets (оригинальные, без чужих персонажей), админская загрузка через ZIP. Группы: до 20 участников (Trial — до 5), создаёт любой, админ при создании с передачей прав, пригласительные ссылки с лимитом использований и сроком, мут/кик, роли админ/модератор/участник, название/аватар/описание, закреплённые сообщения. Геопозиция: живая трансляция (15 мин/час/8 часов как в Telegram) или статичная точка с карты, вложения в чат со ссылкой в мини-браузер, на карте видны все шарящие в чате, глобальный запрет в настройках. Контекстное меню при выделении: копировать/вырезать/вставить/перевести (работает даже при выключенном облаке через локальный fallback с пометкой)/спросить Grok/ChatGPT/Gemini (боковая панель, кнопка вставить обратно). Плюсик: камера, галерея, файл, скан (Tesseract/ML Kit, Qwen-OCR для арабского/азиатских), опрос (как в Telegram: до 10 вариантов, множественный выбор, анонимность, результаты в реальном времени), геопозиция, AI-помощь. Автоисправление с подтверждением (подсветка, тап принять/отклонить, свайп игнорировать), работает при смене языка, словари подтягиваются автоматически, отключается в настройках. Мини-браузер: ссылки подсвечиваются, тап открывает iframe с панелью назад-URL-закрыть, свайп вниз закрывает, история навигации в кнопке «Назад», sandbox без скриптов. Навигация: шторка с навигатором (Google, Apple, Waze, Yandex, 2GIS, OsmAnd, MAPS.ME, Sygic, HERE), конвертация ссылок под каждый, BLE только компьютер-компьютер и Android-Chrome-компьютер (Safari iOS не поддерживает), телефонный обмен — под Kivy. Голосовые адреса: распознавание адреса + номер дома → сразу ссылка для тапа без подтверждения, геокодирование параллельно переводу (серый текст → ссылка), Nominatim. Настройки интерфейса как в Telegram: цвет фона (6 пресетов + пикер), шрифт 12-24px ползунком, акцент (градиент логотипа или палитра), хранятся локально и синхронизируются. Обои чатов: лёгкие паттерны с прозрачностью 20-30%, свои картинки с затемнением, переключение в настройках чата. Логотип: стилизованная T из двух переплетённых волн (звуковая волна встречных языков), градиент бирюзовый-фиолетовый, три варианта SVG в админке. Онбординг: логотип сверху, три кнопки входа (Google/Apple/почта), разделитель «или», «Создать аккаунт», «Создать через passkey», без паролей. Профиль: аватар с кропом (Trial — 1 фото, Premium — без лимита), ник с эмодзи для Premium (белый список Unicode без ZWJ), родной язык, уровень бонусов, часы, бейджи, дата регистрации, статистика, по умолчанию закрытый. Бонусы за часы: 1 час — кастомный акцент, 500 часов — статус «Легенда» с расширенным буфером, пороги из админки, таймер только за активные сессии. AI-агент для новичков: всплывает при первом запуске, объясняет интерфейс голосом на родном языке, предлагает пример, уходит при освоении, контекстная помощь при 3 неверных тапах, язык следует из профиля, азиатские/арабские — на локальных моделях роутера. Реклама: HTML5 video из assets/ads, модалка не закрывается до конца обоих роликов, звук выключен по умолчанию с кнопкой. Аналитика: серверный таймер общий для free/trial (анти-сброс), счётчик показов/досмотров в админке. Месячные лидеры игр: обнуление в конце месяца, топ-1 получает коины от цены Premium (друзья 10%, регион 20%, страна 30%, континент 40%), каждая покупка Premium в расчёт один раз, четыре лестницы (друзья/регион/страна/континент) считаются отдельно, регион по IP, страну можно поменять вручную. Игры: шахматы, шашки, шашки-поддавки, нарды короткие (до 3), нарды длинные (до 7), нарды классические, калах, чинджик (Ludo), Sic Bo (2-4 игрока, банкир по кругу, 100 монет на стол при посадке — отдельный счётчик не из Talk-коинов, стартовая сумма из админки, при выходе не списывается). Каталог игр — один список без региональной группировки, сортировка по популярности. Шторка для игр: карточка сверху, чат живой под ней, свайп вниз/вверх, состояние сохраняется. Зрители: друзья в дружеской игре, участники группы в групповой, видят доску и ходы, ходить не могут, хозяин может закрыть. Заглушка голоса и сообщений зрителей (две кнопки), принудительная заглушка хозяином. Уведомление о ходе: только графический индикатор (пульсирующая рамка/бейдж) + короткая вибрация, без push. Боты: 3 уровня на игру (лёгкий — случайные, средний — жадный, сложный — альфа-бета + RL для шахмат/нард), калибровка под рейтинг, партии с ботом НЕ идут в рейтинг (отдельная статистика тренировок). Шахматы: быстрая (реальное время) или небыстрая (офлайн-буфер ходов с таймстампом, проигрывание со сдвигом на сутки). Рейтинг Elo: четыре лестницы. Talk-коины: не конвертируются из игровых очков. Privacy: «Сообщения и голосовые сегменты обрабатываются на серверах Talking для обеспечения функции перевода. Распознавание речи выполняется локально. Переведённый текст передаётся сторонним API (xAI, Qwen, DeepSeek и др.) — только текст сегмента без привязки к аккаунту. Облачный перевод можно отключить, но функция станет недоступна». Право запросить удаление через админку. Terms: платишь за доступ к сервису и проприетарные модули. README: пошаговая инструкция по хостингу (EKS, Aurora, PgBouncer, HPA, SQS, Cloudflare), переменные окружения, Docker. CI: GitHub Actions — пуш в main = деплой. docker-compose с healthcheck'ами. SECURITY_AUDIT.md с семью слоями (бэкенд, фронт, админка, лицензии, Docker, данные, зависимости), pip-audit + bandit, рейтинг critical-low. GOOGLE_SCOPES.md с чеклистом. NOTICE.md с оговорками (сверь с актуальной редакцией, не юрконсультация) + docs/specs со спецификациями как доказательство человеческого вклада. Все GPL-зависимости (edge-tts, espeak-ng) — в отключённых опциях. Замени их браузерным синтезом и gTTS.

## Owner addendum (2026-11-03) — not part of the verbatim block above

The paragraph 13 sentence «SMS-вход — не в первой версии» is **overridden** by a later owner decision: sign-in and sign-up by **mobile phone number** are in v1. Verification is an SMS code **or** a voice call («call me instead»). Matching phone numbers do **not** auto-merge accounts. Implementation notes: `docs/AUTH.md`. The original wording above is kept as historical evidence of the first specification.
